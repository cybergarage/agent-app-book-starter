# 職種を越える仕事の練習

第4〜7章と付録の新商品企画、説明サイト、返信案などの演習で使います。CodexのProjectでこの`cross-role/`を作業フォルダに選びます。入力は`input/`、完成物は`output/`に置きます。主要な演習の依頼文は`prompts/product-concept-request.txt`などにあります。演習ごとに新しいタスクを始め、本文に示した成果物と確認条件を指定してください。`AGENTS.md`は継続ルールの文案です。公開、メール送信、実在データの入力は行いません。週次レビューの演習では別の`weekly-report/`を使います。
