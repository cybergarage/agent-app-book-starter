# ビジネス向け AI エージェント書籍の練習ファイル

書籍「Codexでつくる仕事の手順」と「Claude Codeでつくる仕事の手順」で使う、架空の週次営業報告教材です。2冊はそれぞれ単独で進められます。実在の顧客、取引、業績は含みません。

| 読んでいる本 | 使うフォルダ |
| --- | --- |
| Codex版 | `codex/weekly-report/` |
| Claude Code版 | `claude-code/weekly-report/` |

## ダウンロード

GitHubのページで **Code → Download ZIP** を選び、ZIPファイルを展開してください。使用する本のフォルダだけを作業場所として選びます。コマンド入力やGitの操作は不要です。

各フォルダに、2週分の入力資料、依頼文、継続する仕事のルール、空の出力先があります。まず該当する製品別READMEを読んでください。

`answer-key/`は著者作成の完成見本と誤り探し用の文書です。AIに指定する作業フォルダの外に置いてあります。自分の出力を確認する段階で開いてください。完成見本はAIの実行結果ではありません。

この教材の操作手順は書籍の先行章に対応します。アプリの画面や指示ファイルの読み込み動作は出版前に確認中です。画面の表示が書籍と違うときは、現在のアプリで作業場所と権限の確認を優先してください。
