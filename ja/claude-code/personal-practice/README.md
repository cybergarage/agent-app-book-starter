# 個人練習の進め方

会社の資料や業務用の指示とは別の作業場所で使います。書籍の演習02・05・08・12・20・21・22の任意練習に対応し、互いを前提にしません。

1. 本文の手順でこの`personal-practice/`フォルダを選び、新しい会話を開きます。
2. `voice-request.txt`は`input/`の二つの文章を読み、ファイルを新規保存します。短い`article-request.txt`と`strengths-request.txt`は材料を含み、回答を会話に表示します。依頼は`prompts/`にあります。
3. 自分の出力を入力と照合します。誤りがあれば、対応する`*-correction.txt`の依頼を実際の誤りに合わせて使います。誤り例と同じ出力になるとは限りません。
4. 短い体験文と強みのメモはOSで保存できます。アプリに保存を頼む場合は、この作業場所の`output/`へ新規保存し、同名ファイルがあれば止めるよう伝えてください。入力やほかのファイルは変更させません。
5. 保存先を会話に表示させ、OSでもファイルを開いて確かめます。ファイルが見つからなければ作業場所と保存先を照合します。
6. 出力確認後に、作業場所の外の`ja/answer-key/personal-practice/`と比べます。名前に`error`を含むファイルは意図的な誤り例です。

`article-long-request.txt`は長い記事を試す任意の依頼です。見出しと改行を除いて300〜450字になっているか数えます。写真やnoteへの投稿は不要です。

継続する指示やスキルの自動登録は行いません。ガイドと判断メモは、新しい会話でファイル名を明示するか、本文を貼り付けて再利用します。実名・連絡先・私信などを教材へ追加する必要はありません。製品の回答・保存・再利用は著者の実機確認待ちです。

収納比較はshelf-request.txt、作品ページはgallery-request.txt、復習はstudy-request.txtを使います。作品ページは計画を確認してから作成を依頼します。語学復習は本文の短い記録を貼り付けても試せます。各訂正依頼は実際の誤りに合わせてください。

手順の再利用はreview-a-request.txt、review-procedure-request.txt、必要な訂正、新しい会話でreview-b-request.txtの順です。A45分とB40分を照合し、未確認の過去形を誤りと断定しません。スキル化は本文の任意発展です。自動登録するスキルは配布作業場所へ入れていません。
