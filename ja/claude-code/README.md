# Claude Code版の練習

本書で使う業務用の4つと個人練習用の1つの作業フォルダは次のとおりです。一度に指定するのは、その章で使う一つのフォルダだけです。

| 章 | 作業フォルダ | 作るもの |
| --- | --- | --- |
| 第3章 | `weekly-report/` | 週次営業報告 |
| 第3章 | `choice-memo/` | 比較メモ |
| 第5章 | `meeting-followup/` | 会議後の対応表 |
| 第4〜8章 | `cross-role/` | 企画・サイト・返信案・提案資料・学習課題・強み |
| 演習03・06・09・13・21・22・23の追加練習 | `personal-practice/` | 文章・比較・ページ・学習・振り返り |

個人向けの追加練習は任意です。業務の作業場所から切り替え、新しい会話で、各依頼に書かれた材料だけを使います。本文の短い入力を貼り付ける場合は、配布教材を取得しなくても試せます。

## 週次営業報告

`weekly-report/`を練習用の業務専用フォルダとして使います。Claude DesktopのCode画面でそのフォルダを選び、1週目と2週目を別のセッションとして進めます。具体的な画面操作はClaude Code版の先行章を参照してください。

1. `weekly-report/input/`に4つの架空資料があることを確かめます。
2. `weekly-report/prompts/request-week-1.txt`の依頼を読み、1週目の新しいセッションで使います。計画が示されたら、使う資料と保存先を確認してから作成を進めます。
3. `weekly-report/output/`にできた報告を元資料と照合します。
4. 翌週は新しいセッションで`request-week-2.txt`を使い、前週との差と未確認事項を照合します。

`AGENTS.md`は継続する仕事のルールの文案です。実際に読み込まれたかどうかは、アプリで作業場所を確認し、応答と保存結果から確かめてください。元資料を変更した場合は元のZIPからコピーし直し、既存の報告は上書きしないでください。

比較メモと会議後の対応表も、各フォルダの`input/`と`prompts/request.txt`を使います。作成したファイルは、そのフォルダの`output/`に保存してください。章の最後に`ja/answer-key/`の著者作成見本と照合します。
