# Claude Code版：週次営業報告

`weekly-report/`を練習用の業務専用フォルダとして使います。Claude DesktopのCode画面でそのフォルダを選び、1週目と2週目を別のセッションとして進めます。具体的な画面操作はClaude Code版の先行章を参照してください。

1. `weekly-report/input/`に4つの架空資料があることを確かめます。
2. `weekly-report/prompts/request-week-1.txt`の依頼を読み、1週目の新しいセッションで使います。計画が示されたら、使う資料と保存先を確認してから作成を進めます。
3. `weekly-report/output/`にできた報告を元資料と照合します。
4. 翌週は新しいセッションで`request-week-2.txt`を使い、前週との差と未確認事項を照合します。

`CLAUDE.md`は継続する仕事のルールの文案です。実際に読み込まれたかどうかは、アプリで作業場所を確認し、応答と保存結果から確かめてください。元資料を変更した場合は元のZIPからコピーし直し、既存の報告は上書きしないでください。
