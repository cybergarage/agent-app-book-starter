# Business AI Agent Book Starter / ビジネス向けAIエージェント書籍の教材

Practice files for two independent books: a Codex edition and a Claude Code edition. The Japanese materials are available in [`ja/`](ja/README.md). An English edition is planned; its files will be added under `en/` after translation and review.

Codex版とClaude Code版の書籍で使う練習ファイルです。現在利用できるのは[日本語版 `ja/`](ja/README.md)です。英語版は翻訳・確認後に`en/`へ追加する予定です。

| Edition / 書籍 | Japanese files / 日本語教材 | English files / 英語教材 |
| --- | --- | --- |
| Codex | [`ja/codex/`](ja/codex/README.md) | Planned / 準備中 |
| Claude Code | [`ja/claude-code/`](ja/claude-code/README.md) | Planned / 準備中 |

Each book can be used on its own. The practice data is fictional. The answer key is outside each AI working folder. Readers can choose **Code → Download ZIP** on GitHub; no terminal or Git commands are needed.

各冊は単独で使えます。データは架空のものです。完成見本はAIへ指定する作業フォルダの外にあります。GitHubの **Code → Download ZIP** から取得でき、ターミナルやGitの操作は必要ありません。
